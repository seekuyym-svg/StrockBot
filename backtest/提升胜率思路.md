## 🔍 连续5期负收益的“隐性真凶”

你的策略本质上是一个“100分综合分 + 优选分（Momentum & Volume）”的短线强趋势延续/突破策略。既然是突破和强动量，它就天然存在三个无法避开的死穴：

### 1. 评分趋势走势（逐日升高）带来的“过热盲区”

在 `_calc_pref_and_veto` 中，有这么一段评分趋势加分：


**致命点：** 综合评分逐日升高，加上之前的“放量3天”，意味着这只股票在买入前已经至少在市场上**高调暴露了3-4天**。在A股目前的存量博弈和极端快节奏的短线生态下，私募和游资非常喜欢在放量第3-4天（也就是你评分最高、刚好达到65-70分、打满加分项的时候）进行“兑现”。你本意是买“逐步走强”，结果大概率接盘了“情绪最高潮”。

### 2. “大盘相对强度限制”在震荡/下跌市中的“假信号”

在股票池生成里，你限制了相对大盘的超额收益：


**致命点：** 如果最近A股处于缩量阴跌、大盘拖累或者风格极其撕裂（比如只有红利低波在涨，小盘股泥沙俱下）的行情里，一只股票可能只是“没怎么跌”或者“跟着某天护盘拉了一下”，它的相对强度就瞬间爆表，冲进你的股票池。但这并不是因为它自身有主力资金发动攻势，而是因为大盘太弱而被动显得强。一旦买入持有2-3天，大盘止跌补跌，它就会**补跌**得比谁都狠。

### 3. 持仓2-3天：缺乏对“亏钱效应”的动态熔断

你选定10只股票后，是机械式地持有2-3天卖出。这在顺周期（赚钱效应好）的时候很舒服；但在连续逆周期时，如果第1天开盘直接低开低走，策略没有主动认错机制（比如分时破位止损、情绪崩溃日空仓），这10只股票的负反馈会互相叠加，导致连续数期录得大额负收益。

## 实现一个全市场情绪开关

实现一个“全市场情绪开关”的核心逻辑非常简单：**用全市场的整体赚钱/亏钱效应，来决定你的短线策略今天是要“猛踩油门”还是“空仓关灯”。**

在A股的短线生态里，最能敏锐反应资金情绪的指标往往不是上证指数，而是**涨跌停家数、连板高度、以及前一日最强股票（赚钱效应最热的地方）在今天的表现**。

下面为你提供一个标准的、工业级的 Python 全市场情绪开关模块。你可以直接将其封装成一个类，或者写进你的 `generate_daily_stockpools` 逻辑中。

## 🛠️ 全市场情绪开关代码实现

我们可以通过引入 `Tushare` 或 `AkShare`（A股常用的开源数据接口）来获取每日的市场全局数据。这里以常用且免费的 `AkShare` 为例进行编写：

```python
import pandas as pd
import numpy as np
import akshare as ak

class MarketEmotionSwitch:
    def __init__(self, limit_up_threshold=30, limit_down_threshold=10, yesterday_limit_up_ret_threshold=-0.02):
        """
        :param limit_up_threshold: 全市场涨停家数下限，低于此值说明市场极度冷清
        :param limit_down_threshold: 全市场跌停家数上限，高于此值说明恐慌盘涌出
        :param yesterday_limit_up_ret_threshold: 昨曾涨停或昨日连板今日的平均收益率下限，用于监控“接力亏钱效应”
        """
        self.limit_up_threshold = limit_up_threshold
        self.limit_down_threshold = limit_down_threshold
        self.yesterday_limit_up_ret_threshold = yesterday_limit_up_ret_threshold

    def get_market_summary(self) -> dict:
        """
        获取当日全市场盘面宏观数据
        """
        try:
            # 1. 获取当日A股实时行情（一般在15:00后或尾盘14:45获取）
            df_current = ak.stock_zh_a_spot_em()
            
            # 过滤掉ST股以保证短线情绪的纯粹性
            df_clean = df_current[~df_current['名称'].str.contains("ST|退")]
            
            # 计算涨跌停（通常以涨跌幅 >= 9.9% 和 <= -9.9% 粗略计算）
            limit_up_count = len(df_clean[df_clean['涨跌幅'] >= 9.9])
            limit_down_count = len(df_clean[df_clean['涨跌幅'] <= -9.9])
            
            # 上涨家数与下跌家数
            up_count = len(df_clean[df_clean['涨跌幅'] > 0])
            down_count = len(df_clean[df_clean['涨跌幅'] < 0])
            up_down_ratio = up_count / (down_count + 1) # 避免除以0
            
            return {
                "limit_up_count": limit_up_count,
                "limit_down_count": limit_down_count,
                "up_down_ratio": up_down_ratio,
                "total_stocks": len(df_clean)
            }
        except Exception as e:
            print(f"获取全市场宏观数据失败: {e}")
            # 如果接口报错，默认返回安全值，不影响交易或默认不熔断
            return {"limit_up_count": 50, "limit_down_count": 0, "up_down_ratio": 1.0, "total_stocks": 5000}

    def get_yesterday_limit_up_performance(self) -> float:
        """
        计算昨日涨停股票在今天的平均表现（衡量短线接力资金的死活）
        """
        try:
            # 获取昨日涨停股池在今天的表现
            # 注：AkShare 提供了现成的“昨日涨停股今日表现”接口
            df_zt_performance = ak.stock_zt_pool_sub_together_em()
            if df_zt_performance.empty:
                return 0.0
            
            # 计算这些股票今天的平均涨跌幅
            avg_return = df_zt_performance['今日涨跌幅'].mean() / 100.0 # 转换成小数
            return avg_return
        except Exception as e:
            print(f"获取昨日涨停今日表现失败: {e}")
            return 0.0

    def is_market_safe(self) -> tuple[bool, str]:
        """
        核心开关控制：判断今天是否适合开仓
        :return: (是否安全, 原因描述)
        """
        summary = self.get_market_summary()
        zt_ret = self.get_yesterday_limit_up_performance()
        
        # 条件一：跌停家数激增（市场出现恐慌性砸盘，泥沙俱下）
        if summary["limit_down_count"] > self.limit_down_threshold:
            return False, f"熔断：当前跌停家数 {summary['limit_down_count']} 家，超过阈值 {self.limit_down_threshold}，恐慌盘蔓延。"
            
        # 条件二：涨停家数过少（全市场几乎没有赚钱效应，资金都在防守）
        if summary["limit_up_count"] < self.limit_up_threshold:
            return False, f"熔断：当前涨停家数仅 {summary['limit_up_count']} 家，低于阈值 {self.limit_up_threshold}，短线资金极度冷清。"
            
        # 条件三：昨日涨停今天大面积闷杀（短线接力极度亏钱，买入容易吃大面）
        if zt_ret < self.yesterday_limit_up_ret_threshold:
            return False, f"熔断：昨日涨停股今日平均收益为 {zt_ret*100:.2f}%，低于阈值 {self.yesterday_limit_up_ret_threshold*100}%，接力亏钱效应严重。"
            
        # 条件四：全市场涨跌比极其恶劣
        if summary["up_down_ratio"] < 0.25: # 意味着 1 支股票上涨的同时有 4 支在下跌
            return False, f"熔断：全市场涨跌比仅为 {summary['up_down_ratio']:.2f}，属于极端普跌行情。"

        return True, "市场情绪正常，允许开仓选股。"

```

## 🔁 如何集成到你现有的策略代码中？

在你原有的主循环或每日策略执行函数（如 `generate_daily_stockpools`）中，在**调用选股和评分逻辑之前**，先调用这个开关。

```python
# 示例：在你的策略主调度中集成
def run_strategy_daily(self, current_date):
    # 1. 初始化情绪开关
    emotion_switch = MarketEmotionSwitch(
        limit_up_threshold=35,               # 涨停少于35家就不玩
        limit_down_threshold=15,             # 跌停多于15家就防守
        yesterday_limit_up_ret_threshold=-0.015 # 昨连板今天平均亏1.5%以上就空仓
    )
    
    # 2. 检查今日市场情绪
    is_safe, reason = emotion_switch.is_market_safe()
    
    if not is_safe:
        print(f"[{current_date}] {reason} ---> 今日放弃选股，全仓保持空仓或锁仓。")
        return [] # 直接返回空列表，不执行后续的评分和买入逻辑
        
    print(f"[{current_date}] {reason} ---> 启动选股引擎。")
    
    # 3. 如果安全，再执行你原有的选股与评分代码
    raw_pools = self.generate_daily_stockpools()
    final_selected = []
    
    for code in raw_pools:
        # 你原有的 _calc_pref_and_veto 评分逻辑
        score = self._calc_pref_and_veto(code) 
        if score >= 60:
            final_selected.append((code, score))
            
    # 按分数排序取前10
    final_selected = sorted(final_selected, key=lambda x: x[1], reverse=True)[:10]
    return final_selected

```

## 💡 为什么这个开关能救你的短线策略？

短线量化策略（尤其是你写的这种放量动量延续策略）最怕遇到“情绪退潮期”**。
在退潮期里，资金会无差别地对前几天的强势股进行“获利了结”。因为你的策略没有全市场视野，它只在自己的100只备选股票池里找“相对最强的10只”。如果全市场都崩了，这10只所谓的“最强股”其实只是**跌得慢的炮灰，你买进去刚好赶上它们的补跌。

加上这个开关后：

1. **防范集体闷杀：** 只要昨日最强的那批股票（昨日涨停池）今天开盘集体低走（比如平均跌-2%），开关立刻触发熔断。这说明市场开始杀高位股了，你的策略由于选的也是高位放量股，今天进去必死无疑。
2. **过滤极端普跌：** 遇到4000只股票下跌、只有红利护盘的恶劣日子，涨跌比低于0.25，开关自动关灯，绝不进去当逆行者。

你可以用这套逻辑去跑一下你过去5期负收益的那几天，我敢说其中至少有3到4天，这个开关会高高挂起**红灯（熔断）**，从而帮你保住宝贵的本金！
